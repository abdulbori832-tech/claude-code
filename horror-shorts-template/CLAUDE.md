# Horror Shorts — рабочая папка (свой шаблон)

Ты работаешь для человека без технического опыта. Пиши по-русски, коротко и просто, без терминов.
Ролики — на **английском**: вертикальные хоррор-шортсы 20–60 с. Зритель — главный герой («You…»),
есть правило или ограничение, напряжение растёт, поворот в последние 2–3 секунды.
Стиль описан в `STYLE.md` — соблюдай его. Рекламу сервисов не вставляй. Озвучка — любая (сервис или свой голос).

## Где что лежит
- `studio/` — видеостудия (Remotion + three.js). Движок: `studio/src/engine/` (персонажи, свет, камера, субтитры).
  Каждый ролик — папка `studio/src/shorts/<имя>/Short.tsx` + `studio/public/<имя>/` (voice.wav, words.json, cues.json, mix.wav).
  Главный пример — `shorts/floor13` («The Thirteenth Floor», 42 с, стиль Dark Toon: 3 локации, 19 планов, рука на кнопке,
  табло этажей, скример). Короткие примеры: `shorts/mannequins-toon` (toon), `shorts/mannequins` (dark).
- `tools/` — `voice_words.py` (тайминг слов), `horror_sfx.py` (звук и сведение), `qa.py` (проверка), `draft_voice.py` (черновой голос).
- `Озвучка/` — сюда клиент кладёт mp3/wav и, по желанию, .txt с текстом. `Готовые ролики/` — результат.
- Для работы студии на компьютере: `~/horror-studio` (копия `studio/` латиницей, без пробелов), Python-окружение `~/hs-venv`.

## «Установи»
Без вопросов, клиенту — только итог.
1. Node.js 18+, Python 3.10+, ffmpeg (Mac — Homebrew, Windows — winget, Linux — apt).
2. `python3 -m venv ~/hs-venv` и `pip install faster-whisper soundfile numpy scipy`; скачать модель:
   `python -c "from faster_whisper import WhisperModel; WhisperModel('small.en', device='cpu', compute_type='int8')"`.
3. Скопировать `studio/` в `~/horror-studio`, там `npm install`.
4. Проверочный кадр: в `~/horror-studio` `npx remotion still src/index.ts Floor13 out/check.png --frame=560 --scale=0.5`.
   Показать клиенту. Ответ: «Установка готова. Напишите «Придумай темы» или пришлите озвучку и напишите «Сделай ролик».»

## «Придумай темы»
10 своих хоррор-тем (см. `Темы.md` — формат). Каждая: правило/ограничение, 1–2 места, 1–3 персонажа,
поворот в конце. Не повторять сюжеты чужих каналов (и вдохновляющих: RicksClips, «Кадр 404»).
Сохранить в `Темы.md`, выдать списком: **№. Название по-русски** — первая фраза на английском — чем зацепит.

## «Напиши текст» / номер темы
Английский текст 50–150 слов (20–60 с): первая фраза — сразу ситуация («You took the night shift…»), короткие
фразы, счёт/правило, последняя фраза — поворот. Сохранить в `Озвучка/<тема>.txt`, выдать одним блоком:
«Озвучьте этот текст (низкий спокойный мужской голос) и положите mp3 в папку «Озвучка».»

## «Сделай ролик»
1. Нет студии — сначала «Установи». Озвучка — самый новый аудиофайл в `Озвучка/` без папки в `Готовые ролики/`.
   Нет аудио — попросить озвучку и остановиться. (Для проверки темпа можно `tools/draft_voice.py`, но не как финал.)
2. `python tools/voice_words.py <аудио> ~/horror-studio/public/<имя>` → voice.wav + words.json.
   Числа и сокращения в words.json привести к виду для субтитров (9 → NINE, 3 a.m. → «3 A.M.»), слову-поворту
   в конце поставить `"x": 1` (красный).
3. Скопировать `shorts/floor13` в `shorts/<имя>`, переписать: SHOTS (планы и камера по времени слов, кадр = секунда*30),
   набор (`Store` → свой набор из `engine/toon.tsx`: PaintedFloor/PaintedWall/OBox/WarmLamp/ToonWindow/ToonRack/Shelf/Poster/Glow + Picture), персонажей (`engine/draw.ts`:
   новые виды рисуются там же, в том же стиле), эмоции по сюжету, мигание света, финальный «скример» и затемнение.
   Зарегистрировать композицию в `src/Root.tsx`. FRAMES = длина голоса + ~1 с.
4. `cues.json` по сюжету (гул, шаги, треск ламп, сердцебиение, нарастание, удар на слове-повороте) →
   `python tools/horror_sfx.py cues.json voice.wav mix.wav` (громкость −14 LUFS).
5. Проверочные кадры каждого плана (`npx remotion still … --frame=N --scale=0.4`): лица читаются, субтитры не
   закрывают главное, нет пустых кадров. Починить и только потом финальный рендер:
   `npx remotion render src/index.ts <Id> out/<имя>.mp4 --codec h264 --crf 16 --timeout=180000`.
6. `python tools/qa.py out/<имя>.mp4`. Результат в `Готовые ролики/<имя>/`: mp4, `Заголовки и описание.md`
   (3 заголовка, описание, хэштеги), `обложка.jpg` (самый страшный кадр), `отчёт.md`.
7. Клиенту 3–5 строк: где ролик, что получилось, «Если что-то поправить — напишите «Поправь: …»».

## «Поправь: …»
Правка последнего ролика, перепроверить затронутое, перерендерить. Старый файл → `…_v1.mp4`. Ответ 1–2 строки.
